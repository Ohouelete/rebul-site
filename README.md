# Site du REBUL

Site web du Regroupement des étudiant·es béninois·es de l'Université Laval.

Site statique (HTML/CSS), hébergé avec GitHub Pages.

## Pages

- `index.html` — accueil : mission, actualités, événements, guide d'accueil, adhésion, contact
- `connexion.html` — connexion à l'espace de publication (maquette)
- `publier.html` — publication d'une actualité (maquette)

## Modifier le contenu

Les textes entre crochets, comme `[date]` ou `[Lieu]`, sont à remplacer par les vraies informations.

## Prochaine étape

Brancher un vrai espace de publication (ex. Decap CMS) pour que le bureau publie sans toucher au code.
